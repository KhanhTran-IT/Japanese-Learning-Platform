## 2. Tầm nhìn sản phẩm

Website nên được xây dựng dựa trên 5 trụ cột chính.

### 2.1. Học theo khóa học

Bao gồm:

- Khóa học miễn phí.
- Khóa học trả phí.
- Khóa học theo cấp độ JLPT: N5, N4, N3, N2, N1.
- Bài học video.
- Bài học audio.
- Nội dung text.
- File PDF/tài liệu đính kèm.
- Quiz sau bài học.
- Theo dõi tiến độ hoàn thành.

### 2.2. Luyện tập tương tác

Bao gồm:

- Flashcard từ vựng.
- Flashcard Kanji.
- Quiz ngữ pháp.
- Quiz nghe hiểu.
- Bài tập điền từ.
- Bài tập sắp xếp câu.
- Bài tập chọn nghĩa đúng.
- Bài tập chọn cách đọc đúng.

### 2.3. Game hóa việc học

Bao gồm:

- Điểm kinh nghiệm, gọi là XP.
- Cấp độ học viên.
- Streak học tập hằng ngày.
- Nhiệm vụ hằng ngày.
- Huy hiệu thành tích.
- Bảng xếp hạng.
- Mini game từ vựng.
- Mini game Kanji.
- Mini game nghe hiểu.

### 2.4. Kinh doanh khóa học

Bao gồm:

- Bán khóa học lẻ.
- Bán combo khóa học.
- Gói membership học toàn bộ khóa.
- Mã giảm giá.
- Thanh toán online.
- Lịch sử đơn hàng.
- Quản lý doanh thu.
- Quản lý hóa đơn.

### 2.5. Quản trị vận hành

Bao gồm:

- Quản lý học viên.
- Quản lý khóa học.
- Quản lý bài học.
- Quản lý quiz.
- Quản lý flashcard.
- Quản lý game.
- Quản lý đơn hàng.
- Quản lý thanh toán.
- Quản lý banner.
- Quản lý cấu hình website.
- Báo cáo doanh thu.
- Báo cáo học tập.
