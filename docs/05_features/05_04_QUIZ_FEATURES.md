## 5.4. Nhóm chức năng quiz

### 5.4.1. Loại câu hỏi

Hệ thống nên hỗ trợ:

```text
Single choice
Multiple choice
True/False
Fill in the blank
Matching
Listening choice
Reorder sentence
```

### 5.4.2. Quiz

Một quiz gồm:

```text
Tên quiz
Mô tả
Bài học liên quan
Thời gian làm bài
Điểm đạt tối thiểu
Số lần làm tối đa, optional
Danh sách câu hỏi
```

### 5.4.3. Kết quả quiz

Lưu:

```text
User làm quiz nào
Bắt đầu lúc nào
Nộp lúc nào
Tổng điểm
Số câu đúng
Số câu sai
Đạt/không đạt
Chi tiết đáp án từng câu
```
