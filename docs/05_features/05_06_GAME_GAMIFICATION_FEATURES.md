## 5.6. Nhóm chức năng game học tiếng Nhật

### 5.6.1. Mini game ghép từ

Ví dụ:

- Ghép từ tiếng Nhật với nghĩa tiếng Việt.
- Ghép Kanji với cách đọc.
- Ghép Hiragana với Romaji.

### 5.6.2. Mini game nghe hiểu

Ví dụ:

- Phát audio tiếng Nhật.
- User chọn đáp án đúng.
- Tính điểm theo tốc độ và độ chính xác.

### 5.6.3. Mini game chọn Kanji

Ví dụ:

- Hiển thị nghĩa tiếng Việt.
- User chọn Kanji đúng.
- Có giới hạn thời gian.

### 5.6.4. Leaderboard

Leaderboard gồm:

```text
Top ngày
Top tuần
Top tháng
Top toàn thời gian
Top theo từng game
Top theo từng cấp độ JLPT
```

### 5.6.5. XP, level và badge

Cơ chế:

```text
Hoàn thành bài học: +XP
Làm quiz đạt điểm cao: +XP
Chơi game: +XP
Học liên tục nhiều ngày: nhận badge
Hoàn thành khóa học: nhận chứng chỉ/badge
```
