## 5.3. Nhóm chức năng học tập

### 5.3.1. Theo dõi tiến độ học

Hệ thống cần lưu:

```text
User học bài nào
Đã xem bao nhiêu phần trăm video
Đã hoàn thành bài chưa
Hoàn thành lúc nào
Điểm quiz cuối bài
Tiến độ tổng khóa học
```

### 5.3.2. Dashboard học viên

Hiển thị:

```text
Khóa học đang học
Bài học gần nhất
Tiến độ từng khóa
Nhiệm vụ hôm nay
Điểm XP
Streak học tập
Khóa học đề xuất
Lịch sử quiz gần đây
```
