## 5.9. Nhóm chức năng admin

### 5.9.1. Dashboard admin

Hiển thị:

```text
Tổng số user
User mới hôm nay
User mới tháng này
Tổng số khóa học
Tổng số đơn hàng
Doanh thu hôm nay
Doanh thu tháng này
Top khóa học bán chạy
Tỷ lệ hoàn thành khóa học
Số lượt làm quiz
Số lượt chơi game
```

### 5.9.2. Quản lý user

Chức năng:

```text
Danh sách user
Tìm kiếm user
Lọc theo role
Lọc theo trạng thái
Khóa/mở tài khoản
Xem chi tiết user
Xem khóa học đã mua
Xem lịch sử học
Gán role
```

### 5.9.3. Quản lý khóa học

Chức năng:

```text
Thêm/sửa/xóa khóa học
Ẩn/hiện khóa học
Cài giá bán
Cài giảm giá
Upload ảnh đại diện
Sắp xếp khóa học
Gán teacher
```

### 5.9.4. Quản lý bài học

Chức năng:

```text
Thêm/sửa/xóa chương
Thêm/sửa/xóa bài học
Upload video/audio/pdf
Sắp xếp thứ tự bài học
Cài bài học miễn phí xem thử
Gán quiz cho bài học
```

### 5.9.5. Quản lý quiz

Chức năng:

```text
Tạo quiz
Tạo câu hỏi
Tạo đáp án
Đánh dấu đáp án đúng
Import câu hỏi từ Excel
Xem thống kê kết quả quiz
```

### 5.9.6. Quản lý game

Chức năng:

```text
Quản lý game
Quản lý level game
Quản lý dữ liệu từ vựng game
Quản lý leaderboard
Xem lịch sử chơi game
```

### 5.9.7. Quản lý đơn hàng

Chức năng:

```text
Danh sách đơn hàng
Lọc theo trạng thái
Lọc theo thời gian
Xem chi tiết đơn hàng
Xem thanh toán
Xuất Excel
Hoàn tiền, nếu cần
```

### 5.9.8. Cấu hình website

Chức năng:

```text
Tên website
Logo
Favicon
Banner trang chủ
Thông tin liên hệ
Email hỗ trợ
Số điện thoại
Facebook
Zalo
TikTok
SEO title
SEO description
Chính sách bảo mật
Điều khoản sử dụng
Cấu hình email
Cấu hình thanh toán
```
